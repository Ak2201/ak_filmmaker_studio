Tamil screenplay format

There is no single official Tamil screenplay standard. This is the layout many Tamil units work with, and the reasons behind each part of it.

Updated 26 October 2026

On this page

  1. The common layout
  2. Scene headings
  3. Action, cues and dialogue
  4. Why the page count needs a fixed-width face
  5. In the studio

The common layout

A common way to write a Tamil screenplay is the standard screenplay format with the dialogue in Tamil: scene headings and action in English, so every department head and every crew member from outside Tamil Nadu can read them, and the dialogue in Tamil script or in Tanglish (Tamil written in Roman letters), the way the actors will say it.

Whichever you choose, agree it with your assistant director before the first draft is shared. A script that switches between Tamil script and Tanglish from scene to scene is harder to break down and harder to subtitle.

Scene headings

Each scene starts with a heading in capitals: INT. or EXT. (inside or outside), the location, and the time of day after a dash, for example INT. COLLEGE CANTEEN - DAY. Use INT./EXT. for a scene in a car or across a doorway.

The heading is what the schedule is built from, so keep a location's name the same every time it appears. TEA SHOP and TEA STALL will be scheduled as two places.

Action, cues and dialogue

  • Action is in the present tense and short: three or four lines, then a new paragraph.
  • The character's name above each speech is in capitals and spelled the same every time, so the cast list counts one person, not two.
  • A parenthetical is one short note on how a line is said, such as (quietly) or (to Meena). Anything longer is action.
  • Dialogue sits in its own narrow column. Write it the way it will be spoken, in Tamil script or Tanglish, and keep songs or lyrics clearly marked.

Why the page count needs a fixed-width face

The rule of thumb that a page is about a minute of screen time holds only because a screenplay is set in 12-point Courier, a face where every character is the same width. That fixed grid is what makes a page count predictable.

Tamil script is not fixed-width, so a page with long Tamil passages in the structural parts (headings and action) no longer measures what an English page measures. Keeping Tamil to the dialogue keeps the rest of the page on the grid, and the page count stays meaningful for scheduling.

In the studio

The Screenplay Writer sets the format as you type: Return and Tab pick the next element, scene headings are recognised and each one becomes a scene in the studio.

Tamil typing (Alt+T) is an opt-in mode for dialogue and parentheticals: type a word in Roman letters and it is offered in Tamil script, committed with Space or Return. Headings and action are left as you typed them, which is what keeps the page count exact.

A format guide notes common slips, such as a heading without INT. or EXT., a heading with no time of day, or a character name not in capitals. The finished script exports as PDF, Word, Final Draft and Fountain.
