A breakdown you check, not one you type

Run the breakdown and every scene heading becomes a scene, with the cast its character cues name already tagged. The rest you tag once, on the scene, so the breakdown stays your decision.

Every tag you accept feeds the element list, the schedule, the day out of days and the budget. Change the script and the scenes update, so the paperwork never drifts from the film.
